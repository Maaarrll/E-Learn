How to set up ALLEARN

For the classroom laptop. No internet, no installing, about 5 minutes.

You need:
  • The file ALLEARN-Portable.zip (on a USB drive).
  • A Windows laptop.
  • A Wi-Fi router for the classroom. It does not need internet.

Set up (only once)

1

Copy the zip to the laptop

Plug in the USB and copy ALLEARN-Portable.zip to the laptop.

2

Unzip it to the C: drive

  • Right-click the zip → Extract All...
  • Type C:\ as the place to extract to, then click Extract.
  • You now have a folder C:\ALLEARN.

Don't extract to the Desktop or Documents. Those are often synced by OneDrive, which can break the database.

3

Start ALLEARN

  • Open C:\ALLEARN and double-click Start ALLEARN.
  • If a blue box says "Windows protected your PC": click More info → Run anyway.
  • If Windows Firewall asks about Node.js: tick both boxes (Private and Public) and click Allow.
4

Make the teacher account

The black window asks for the teacher's full name, a login ID (for example teacher1) and a password (typed twice; the letters stay hidden). Write the ID and password down somewhere safe.

A Start ALLEARN icon is now on the desktop, and a page opens with the class address and a QR code.

5

Test with one phone

  • Connect the laptop and the phone to the same Wi-Fi. Turn the phone's mobile data off.
  • Scan the QR code. If the ALLEARN login page opens, setup is done.

Every class

✓
  • Connect the laptop to the classroom Wi-Fi and double-click Start ALLEARN on the desktop.
  • Show the QR code page on the projector. Open the Admin page, log in and open the class.
  • After class: close the class, then close the black window.

Print Teacher Card.html (in the ALLEARN folder) and keep it next to the laptop.

If something goes wrong

Phones can't open the pageCheck they're on the same Wi-Fi with mobile data off. Then, in C:\ALLEARN, right-click Setup ALLEARN → Run as administrator (this fixes the firewall).
No icon on the desktopRun Setup ALLEARN as administrator, or start from C:\ALLEARN\Start ALLEARN.
Teacher forgot the passwordAnother main admin resets it in Admin → Instructors. Add a second main admin early for this reason.
The black window shows an errorTake a photo of it and send it to support.

Keep the data safe

Everything (accounts, progress, videos, photos) is in C:\ALLEARN\classroom-data. ALLEARN makes a daily backup inside it, but copy that folder to a USB drive every week. Never delete it.

Moving to another laptop: close ALLEARN, copy the whole C:\ALLEARN folder (with classroom-data inside) to the new laptop's C: drive, and start it there.
